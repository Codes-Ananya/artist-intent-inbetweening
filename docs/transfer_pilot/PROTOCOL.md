## Fixed prospective procedure v0.1 (not an implemented inference runner)

Freeze the procedure and annotation fields before any case output is viewed. SFP's hard-coded coordinates, ellipse patch, cleanup rectangle and hand-tuned rotations are **not transferable settings**. Existing SFP runners must not be pointed at these inputs.

Common scope: one named foreground arm, two connected rigid segments, fixed foreground-over-torso order. No body-turn reconstruction, additional limbs, hand redrawing, new pose generation or per-case algorithm branch. If source identity/depth/correspondence cannot be annotated consistently from endpoints, record abstention before rendering. These limits may reject T02/T03; that is an informative transfer limitation, not a reason to tune them.

Common intended recipe for a future config-driven runner:

1. Endpoint-only annotation: two arm masks split at elbow, shoulder/elbow/wrist landmarks, one arm/torso ROI and explicit depth-order/visibility flags. Annotator must not inspect baseline outputs or references until annotations are frozen. Log prior exposure honestly.
2. Use the same endpoint-derived placement rule for every case: linear midpoint shoulder/elbow targets; rotate source pieces by half of the shortest signed endpoint segment-angle difference, unit scale, connect at the target elbow. Fixed source endpoint is the later pose. No hand-selected midpoint angles or scaling. If this does not fit endpoint segment lengths/visibility, abstain rather than alter the rule. This rule is a *new prospective transfer specification*, not a verified generalization of the accepted SFP frame.
3. Preserve the same ROI-compositing concept. Plate observations come from endpoints only. A torso that cannot be treated as locally aligned makes cross-endpoint pixel reuse unjustified; abstain unless a single preregistered alignment method is implemented and validated for all cases before the pilot. Do not add alignment after one case fails. Current candidates show enough torso change that this is a real blocker.
4. Unknown plate pixels remain explicitly marked. One fixed 5×5 dilation and Telea radius 3 is the only allowed estimate; save observed-source, unknown, exposed-unknown and final coverage masks. No manual artwork/cleanup patches during this transfer test. This deliberately removes the SFP-specific repair advantage. Any result remains uncertain reconstructed artwork, not known vest texture.
5. Warp premultiplied RGB/alpha with bilinear sampling; normalize overlap, preserve pixels outside the declared ROI and both endpoint images exactly. No other treatment-specific tuning. A generic annotated runner and synthetic transformation tests must exist before execution; currently only the preparation/audit runner is implemented.

Baseline for every case: local pinned RIFE, scale 1, float32, `cuda:0`, one t=0.5 output at 512×512. Same two image inputs and one candidate midpoint in the layered condition, with extra manual annotations explicitly charged. Process cases sequentially on RTX 4050; one RIFE midpoint per case (three total), CPU compositing, no downloads. CUDA failure must stop/record failure; no CPU crossfade substitution. Current prep does not require GPU. The midpoint denotes a chosen temporal probe between supplied indices, not a claim that these sparse generated poses encode validated timing. Compare triplets at fixed 125 ms per displayed image; disclose omitted source timeline slots and label any loop reset. Preserve native source indices in metadata.

## Evaluation and permissible conclusions

Before rendering, declare acceptance checks: exact endpoints/outside-ROI pixels; opacity of the intended limb; contour breaks/seams; joint anatomy and limb identity; continuity of the whole triplet including torso/legs/scarf; new artifacts; annotation effort and uncertain reconstructed area. Rate opacity, contours, anatomy and transitions separately on anchored 1–5 scales (1 severe failure, 3 visible defects, 5 no obvious defect at review scale). Primary exploratory success requires better occlusion/contour ratings without worse anatomy/transition ratings; preserve per-reviewer judgments/ties rather than selecting by opacity alone.

Use at least two independent reviewers, randomized A/B method order per case and concealed method labels for scoring. Keep a mapping outside their packet, then reveal provenance afterward. Review both triplet playback and stills, not only cropped arms. Record disagreements, abstentions and every case; do not replace failures. Independent artist review is required for claims about usefulness to artists, natural/articulated movement or intended motion; visual acceptance by a developer alone is not enough.

Independent temporal ground truth is required for reference-accuracy claims. These inputs cannot support them. If new references are acquired, store them separately and hide them from annotation; never use the evaluated reference as conditioning data. Intent claims additionally require artist-authored target instructions/poses and artist evaluation. Three cases on one new AI character support at most a constrained transfer feasibility/failure report, not broad character/style generalization or statistical superiority.
